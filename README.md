An entry for the [news-image-20261123](https://make.fun/bounty/news-image-20261123)
competition on make.fun: sum up 23 November 2026's world news in one image.
The program draws a 1024x1024 newspaper front page — masthead, date, and the
day's eight most consequential stories — with its own PNG encoder and its own
5x7 bitmap font. Node 22, standard library only, no network, deterministic:
two runs write byte-identical PNGs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png` (1024x1024, under 1 MiB).
